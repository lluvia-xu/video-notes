# 画面拆解框架

画面拆解模式用这份框架逐镜头分析，并写出复刻用的提示词。框架综合了几个开源 skill：
`storyboard-shot-breakdown`（五个导演决策维度，逐镜头追问"为什么"）、
`film-breakdown`（镜头卡里摄影机和剪辑的字段）、
`seedance2-api`（按时间码写分镜提示词的公式）。
在此基础上补了短视频常见的三块：**人物与穿搭、声画卡点、首尾循环**。

## 一、逐镜头记录（每个镜头都填）

| 维度 | 记什么 | 常用词 |
|---|---|---|
| 时间 | 起止时间、时长（来自 shots.json） | |
| 景别 | 起幅 → 落幅，景别有变化就写变化 | 大远景、全景、中全景、中景、中近景、近景、特写、大特写 |
| 角度 | 机位高低和方位 | 平视、俯拍、仰拍、顶拍、第一人称；正面、侧面、侧后方、背后 |
| 运镜 | 机位怎么动（以 motion.json 为准）、**速度曲线**（缓入/缓出/匀速，在哪一秒变速）、比人物快还是慢 | 固定、推、拉、摇、移、跟、升降、环绕、手持晃动、变焦、甩镜、一镜到底；复合运镜写全，如"后拉加上升" |
| 焦段感 | 空间是压缩还是拉伸 | 广角（夸张纵深）、标准、长焦（压缩、背景虚） |
| 构图 | 视线被引到哪里，空间的压力来自哪里 | 三分法、居中对称、引导线、框中框、前景遮挡、留白、对角线、剪影 |
| 人物与动作 | 谁、在做什么、朝哪个方向、手在哪里 | 写清**方向**（向左/向右/走向纵深）和**接触物**（扶桌沿、抚琴键） |
| 穿搭与造型 | 上装、下装、鞋、配饰、发型、颜色 | 变装视频要逐件对比前后 |
| 场景与道具 | 在哪里、空间特征、关键道具 | |
| 光线 | 主光方向和性质 | 顺光、侧光、逆光、剪影、边缘光；硬光/柔光；高调/低调；自然光/人工光 |
| 色调 | 冷暖、饱和、亮度（参考 shots.json 的 luma/sat） | 暖亮、冷灰、低饱和、高反差、胶片颗粒 |
| 画幅 | 有没有黑边（shots.json 的 crop 比原尺寸小就是有遮幅） | 全屏 16:9 / 9:16、宽银幕 2.39:1 黑边 |
| 声音 | 这段的音乐、人声、音效，音量起伏 | |
| 叙事功能 | 这个镜头交代了什么 | 铺垫、转折、强调、隐藏、揭示、回落 |
| **为什么** | 反事实追问：换成常规拍法会损失什么情绪或信息？ | 答案通常就是作者的意图 |

## 二、镜头之间（每个切点都填）

| 维度 | 记什么 |
|---|---|
| 转场方式 | 以 `flow` 的事件为准。硬切、**形状匹配转场**（一个物体的轮廓直接变成下一个场景里同形的物体，如发夹 → 埃菲尔铁塔）、**穿越推进**（镜头冲向一个物体，借模糊或填满画面进入下一场景）、匹配剪辑（动作/形状/方向一致）、**运镜接力**（切点前后运镜方向相同，运动感被延续）、跳切、遮挡转场（物体或身体挡镜头）、甩镜转场、叠化、闪白、变速 |
| 衔接依据 | 切点前后什么保持不变（人物位置、方向、动作、构图），什么在变（服装、场景、色调、画幅） |
| 卡点 | 切点离最近的重音、节拍各差多少毫秒（beats.json 的 cut_alignment）；落在重拍、弱拍还是断音里 |
| 剪辑理由 | 情绪、节奏、动作完成、视线引导，还是声音驱动 |

误差在 ±70ms 内（约 2 帧）算卡上。节拍网格可能差半拍，**以重音（accents）为准**。

## 三、全片

- **结构**：几段、各段时长比例（例如 现实 2s : 幻想 5.5s : 现实 0.4s）
- **节奏**：平均镜头时长、每分钟几刀，快慢在哪里切换
- **反差设计**：前后段在哪些维度同时反转（服装、场景、色调、画幅、运镜稳定度、景别）
- **声画关系**：音乐怎么起、哪里有呼吸点（音量下沉）、哪里断音，各对应什么画面
- **循环**：结尾画面和声音能否接回开头
- **导演逻辑**：3～5 句话说清整体视觉策略
- **可复用规则**：1～3 条可以直接拿去拍、去剪的规则

## 四、写复刻提示词

先判断每段适合怎么做：**实拍**（真人日常、手持感）、**图生视频**（需要和实拍画面接上）、**文生视频**（独立段落）。
需要和实拍接上的段落，最稳的做法是：取实拍段最后一帧 → 用图片编辑模型改成生成段的首帧（保留姿势和位置，只换装、换景）→ 首帧图生视频。

### 首帧图编辑提示词

```
保持图中人物的姿势、身体朝向、在画面中的位置、[手的动作] 完全不变。
场景换成：[空间、关键道具、窗外/背景]。
人物换成：[上装、下装、鞋、发型、配饰]，[朝向，例如背对镜头]。
光线：[主光方向与性质]。色调：[冷暖、饱和]。[画幅]。
```

### 视频提示词（按时间码写分镜，适用即梦/Seedance、可灵、Veo 等）

```
[风格] ___ 风格，___ 秒，___ 画幅，___ 情绪

0–Xs：[景别] + [机位/角度] + [运镜，写清快慢和方向] + [人物动作，写清方向和接触物]
X–Ys：……
Y–Zs：……

[画面] 构图要点 + 场景 + 光线 + 色调 + 质感
[声音] 音乐风格 + 音效（模型支持时）
[参考] @image_file_1 作为首帧 / 人物参考；@video_file_1 参考运镜（模型支持时）
[避免] 不想要的镜头行为，例如人物转身露脸、镜头环绕、快速运动、额外人物、文字
```

写法要点：

- 一段只写**一个主要动作**，5 秒左右最稳。
- 运镜写**方向和速度曲线**："镜头快速后拉并上升，约 1.5 秒后明显减速，缓慢漂移" 比 "后拉" 准确。
- 运镜接力：前后两段运镜方向一致时，提示词里要写出同样的方向。
- 方向要和实拍段一致，写明"向画面右侧""走向纵深"。
- 不想露脸就写"始终背对镜头"，既符合原片，也能避开人脸一致性问题。
- 黑边、降饱和、卡点在剪辑里做更可控，不要指望模型一次生成到位。
- 同时给出中文和英文两个版本，用户按所用模型选择。

### 剪辑步骤

按 beats.json 写清每个切点放在第几秒、对齐哪个重音，以及每段的调色、画幅和变速处理。

## 五、复刻失败排查（用户说"试过没成功"时逐条核对）

1. 两段的**动作、方向、人物在画面中的位置**没对齐 → 匹配剪辑失效，切换显得跳。
2. 切点没落在重音或断音上，或加了溶解、闪白等转场特效。
3. 生成段镜头乱动（模型默认会推近、环绕）、人物转身露脸。
4. 两段反差不够：色调没压、没加黑边，或者实拍段拍得太稳太好看。
5. 生成段太长，动作变形；或者太短，情绪没出来。
6. 首尾没有接上，循环播放时能看到接缝。
