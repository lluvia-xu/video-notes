# 爆款与氛围感分析框架

画面拆解回答的是"怎么拍"，这份框架回答"为什么好看、为什么火"。每一条结论都要落到**看得见、量得到的证据**上（镜头图、shots/motion/beats 的数字、平台数据、评论原话），不写"很有氛围感""很高级"这类空话。

## 一、氛围感从哪来（美学层）

逐项检查，每项写"是什么 → 带来什么感受"。

| 维度 | 看什么 | 工具证据 | 常见对应的感受 |
|---|---|---|---|
| 光 | 光源数量和方向（顺/侧/逆/顶），软硬，明暗比，剪影，边缘光，体积光 | shots.json luma（<90 偏低调，>140 偏高调） | 逆光加剪影：疏离、神秘；柔光加高调：干净、治愈；硬光：张力 |
| 色 | 色温冷暖，饱和度，主色和点缀色，色彩是否成体系，调色风格 | sat（<15 低饱和），hue | 冷灰低饱和：安静、克制、阴郁；暖黄：怀旧、温暖；高饱和：活力、甜 |
| 空间与构图 | 留白（负空间），纵深层次（前/中/后景），框中框，线条方向，人在画面中的占比 | 镜头拼图 | 人小景大：孤独、自由；对称：秩序、仪式感；斜线：动势 |
| 运动 | 运镜方向和**速度曲线**（缓入、缓出、匀速），人物动作快慢，两者方向关系 | motion.json（scale、dy、speed_curve） | 后拉：抽离、揭示环境、"退后看自己"；上升：升华、释放；缓出：落定、沉浸 |
| 时间与节奏 | 镜头时长，快慢对比，呼吸点，停顿 | shots.json、beats.json | 长镜头加慢动作：沉浸；快切：爽、燃 |
| 质感 | 颗粒，光晕，柔焦，锐度，宽银幕黑边，帧率感（24fps 的电影感对比手机 30/60fps） | crop（有黑边） | 黑边加颗粒是"电影感"的视觉符号 |
| 声音 | 音乐情绪（乐器、速度、大小调），环境音，静音的使用，声画同步 | beats.json（BPM、重音、静音段） | 钢琴：文艺、孤独；断音：惊醒、转折 |
| 人物造型 | 服装颜色和场景颜色的关系，轮廓，姿态（松弛/紧绷），露不露脸 | 镜头拼图 | 背影、不露脸：代入感；服装和场景同色系：统一、高级 |
| 符号与母题 | 物件和场景的文化联想（钢琴、落地窗、城市、雨、阴天、旧胶片） | | 借观众已有的联想快速建立情绪 |
| 统一与反差 | 哪些元素统一成体系，哪些元素制造反差 | | 统一产生"高级感"，反差产生"记忆点" |

写完后用一句话总结**氛围配方**：光 + 色 + 空间 + 运动 + 声音，各用几个字概括。

## 二、为什么能火（传播层）

| 维度 | 问题 |
|---|---|
| 钩子 | 前 1～3 秒靠什么留人：视觉反差、悬念、动作起势、音乐重音、文案？ |
| 情绪价值 | 给了观众哪一种情绪：治愈、松弛、孤独、向往、怀旧、燃、爽、好笑？ |
| 代入与投射 | 观众能不能把自己放进去？（背影、第一人称、不露脸、普通人的日常起点） |
| 叙事原型 | 用了哪种人人都懂的结构：现实与理想、前后对比、变装、逆袭、反转、白日梦？ |
| 可参与性 | 普通人能不能低成本复制？有没有模板、同款音乐、固定句式，可以形成二创链？ |
| 完播与复看 | 时长，信息密度，结尾是否回扣开头，能否无缝循环？ |
| 互动触发 | 评论区会自然出现什么：共鸣句、求 BGM、求教程、求同款、玩梗？ |
| 平台适配 | 画幅（竖屏/横屏），封面帧，标题和话题，音乐是否在热门榜 |
| 时机 | 是否借了季节、天气、节日、热点或流行梗？ |

## 三、平台数据（有链接时收集）

有浏览器工具时，在用户已登录的状态下打开视频页，记录：

- 点赞、评论、收藏、转发数，发布时间，作者粉丝数（**互动量 ÷ 粉丝数**比单看点赞更能说明"爆"）
- 同款或模板使用人数（抖音、剪映）、使用的音乐及其热度
- 高赞评论前 20 条：归纳观众自己说的喜欢理由，作为证据引用原话
- 标题、话题标签、封面

没有数据时明确写"以下是基于画面的推测"。

## 四、单条结论要克制

一条视频火，有内容的原因，也有运气、账号权重、发布时间和推荐算法的原因。单条拆解只能给出**假设**。想要更可靠的结论，用调研模式做**对比**：同一模板或题材里的高赞和低赞视频各拆几条，看高赞的共同点是什么、低赞缺了什么。

## 五、平台差异（倾向而非定律）

- **抖音**：前 3 秒留人和音乐卡点权重高；模板和同款音乐带来大量二创。
- **小红书**：封面和第一帧决定点击，"氛围感"和"可收藏"更重要；常与图文笔记竞争。
- **B站**：更看重完整度和信息量，横屏和较长内容更常见。
- **视频号**：社交关系链分发，情感共鸣和熟人转发更重要。

## 六、输出

- **爆款假设**：一句话，例如"用'现实的我 → 理想的我'的白日梦原型，加上低门槛模板，让每个人都能拍出自己的电影感瞬间"
- **氛围配方**：光 / 色 / 空间 / 运动 / 声音，各一行，附证据
- **传播机制**：钩子、情绪、代入、可参与性、完播，各一行
- **可迁移**：这套配方换个题材怎么用（列 2～3 个具体点子）
