# 批量模式：读取我的「喜欢」「收藏」

用户说"读我喜欢的前 20 条""把我收藏的前 30 条转一下""读我『学习』收藏夹的前 5 条"时使用。**读哪个列表（喜欢、全部收藏、某个收藏夹）、读多少条，以用户每次说的为准**；用户说的收藏夹名字找不到时，列出所有收藏夹名称让用户选；没说条数就问，默认 20，单次不超过 50。实现细节和代码见 `references/douyin-batch.md`，**开始前先读它**。

**前提**：需要浏览器工具，且用户已在这个浏览器里登录 douyin.com。没登录就请用户自己扫码登录，不替用户输入账号密码。只读取，不点赞、不取消收藏、不评论。

1. **读列表**：打开列表页，在页面里请求列表接口，用页面上已显示的视频 ID 校验读的是用户自己的列表，然后在页面里提取精简字段（标题、文案、作者、时长、互动数据、平台分类、是否图文）。
2. **出速览表，请用户挑**：按内容分两组。
   - **适合转文字**：口播、教程、经验分享、文章、图文教程。表里列编号、标题、作者、时长、点赞/收藏、一句话判断。
   - **适合画面拆解**：氛围、穿搭、颜值、舞蹈、图集、剧情。
   - 顺带指出值得注意的数据，如收藏接近点赞（干货）、评论接近收藏（问的人多）。
   - 在对话里给出这张表，让用户回复要处理哪几条；先报预计用时，转写约等于视频时长。
3. **逐条处理用户选中的**：按内容类型取素材（视频转写、文章读正文、图文读文案并对图片做 OCR）。逐条打开页面时间隔几秒，直链取到立刻下载。批量筛选时可以跳过字幕校对，同音字在总结里按上下文纠正并注明；用户要引用原话的条目再做校对。
4. **输出**到 `OUT/抖音<喜欢|收藏>_<日期>/`：
   - `汇总.md`：来源和处理说明 → **速览表**（标题、作者、时长、点赞/收藏、类型、一句话、值得细看程度）→ 每条一节（一句话、要点或步骤、值得借鉴、存疑之处）→ 未处理条目列表（注明哪些适合画面拆解）。
   - `文字稿/<编号>_<作者>_<短标题>.txt`：每条的转写原文。
   - 清理音视频和图片，只留文字。
5. 对内容里的说法保持判断：标题和截图不一致、数字没有出处、夸大收益的，在"存疑"里写明。
