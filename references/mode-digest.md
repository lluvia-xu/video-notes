# 收藏日报模式

用户说"出收藏日报""整理我最近的收藏""看看我新收藏了什么""把收藏整理进知识库"时使用。**只在用户开口时运行，不设定时任务。**

和批量模式的区别：批量模式是"读前 N 条、用户挑、逐条总结"；收藏日报是"自动接着上次往下读，每条都读完，产出固定格式的日报和知识卡片，存进知识库"。读列表、取素材的方法与批量模式相同，见 `references/douyin-batch.md`。

笔记格式参考 kepano/obsidian-skills 的 obsidian-markdown（MIT）：卡片带 YAML 属性、标签、`[[双链]]` 和 callout，用 Obsidian 打开能直接按标签、属性筛选；不用 Obsidian 也是普通 Markdown。

## 知识库目录

放在 `OUT/抖音知识库/`。Cowork 里优先放在用户连接的文件夹，这样日报和卡片会留在用户电脑上；没连接文件夹时提醒用户：连接一个（例如 Obsidian 库）才能长期累积。

```
抖音知识库/
├── 日报/2026-10-22 收藏日报.md
├── 卡片/<短标题>.md
├── 文字稿/<视频ID>_<作者>_<短标题>.txt
└── _已处理.json        # 已整理过的视频 ID，下次从这里接着读
```

## 步骤

1. **确定读哪些**：
   - 读 `_已处理.json`。从「全部收藏」列表（`listcollection`，按收藏时间倒序）往下翻，直到碰到已处理过的 ID 为止，中间的都是新收藏。
   - 第一次运行（没有 `_已处理.json`）：问用户从最近几条开始，默认 10 条。
   - 用户说了"今天的""最近 5 条""学习收藏夹"等，就按用户说的范围。
   - 新收藏超过 20 条时先报数量和预计用时（转写约等于视频总时长），问用户是全读还是只读前 20 条。
2. **逐条取素材**：按 `douyin-batch.md` 第 5 节处理视频、文章、图文。视频要**下载带画面的文件**，因为要看前 3 秒。
3. **转写**：`transcribe`（带时间戳）。批量时不做字幕校对，同音字在写作时按上下文改正。
4. **看钩子**：每条用 `sheet <视频> <图> --ss 0 --to 3 --n 6 --cols 6 --width 260` 出前 3 秒的 6 格图；多条时用 ffmpeg `vstack` 拼成一张一起看，省图片 token。结合前 3 秒的口播判断：
   - **钩子在第几秒**：最先抓住注意力的那个东西出现在哪一秒（画面、口播、大字、音效）。
   - **钩子类型**：反差对比、夸张宣称、提问互动、数字或社会证明（star 数、收入）、反常画面、悬念、痛点。
   - 写出原话或原画面，不要只写类型。
5. **判断值不值**：★★★ 有完整可照做的方法或步骤；★★ 有可用的工具或信息，但要再去查原始资料；★ 娱乐或灵感，不必细看。写一句理由。
6. **写知识卡片**：只给"讲了具体方法、操作、工具"的视频写（通常是 ★★ 和 ★★★）。娱乐类只进日报。
7. **写日报、存文件、更新 `_已处理.json`**，清理音视频和截图。
8. **对话里只回复**：几条、哪几条值得看、卡片存在哪里，不贴全文。

## 日报模板

```markdown
---
date: 2026-10-22
type: 收藏日报
count: 5
tags: [抖音收藏, 日报]
---

# 2026-10-22 收藏日报

5 条 · 全部读完 · 视频共 4 分 17 秒 · 生成卡片 3 张

## 1. <标题>｜<作者>｜<时长>｜<点赞>/<收藏>
- **讲什么**：一句话。
- **钩子**：第 X 秒，<类型>：<原话或原画面>。
- **值不值**：★★★ <理由>。→ [[卡片标题]]

（逐条重复）

## 今天的选题和钩子观察
2～4 条：这批收藏里反复出现的选题方向、钩子手法，哪些可以借用到我们的账号。
```

## 知识卡片模板（四格）

```markdown
---
title: <短标题>
source: <抖音链接>
author: <作者>
collected: 2026-10-22
duration: 98
likes: 5245
collects: 2752
hook_sec: 0
follow: 待跟进        # 待跟进 / 已跟进 / 不跟进
tags: [抖音收藏, 主题/AI视频, 类型/教程]
---

# <短标题>

> [!summary] 讲了什么
> 2～4 句：核心观点和结论。

> [!tip] 钩子在第几秒
> 第 X 秒，<类型>：<原话或原画面>。为什么有效。

## 能抄什么
- 可以直接照做的步骤、提示词、工具名（写清楚原文）。
- 可以借用到我们内容里的结构或手法。

## 要不要跟进
- 结论：跟进 / 不跟进，以及下一步具体做什么（例如"去 GitHub 看 xx 仓库的安装说明""用我们的素材试一次"）。
- 存疑：视频自述、没有出处的数字和说法写在这里。

相关：[[主题笔记名]]
```

- 主题标签和双链用稳定的名字（如 `主题/AI视频`、`[[AI 视频生成]]`、`[[开源工具]]`），方便在知识库里聚合。
- 卡片文件名用短标题，不带日期；同一个视频再次收藏时更新原卡片，不重复建。
