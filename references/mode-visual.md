# 画面拆解模式

用户想学"这个视频怎么拍、怎么剪"或想复刻时使用。开始前先读两份框架：`references/visual-breakdown.md`（怎么拍：分镜、运镜、卡点、提示词模板）和 `references/aesthetics-viral.md`（为什么好看、为什么火：氛围感、传播机制、平台数据）。基础的取素材、转写步骤见 SKILL.md。

1. **取视频**：按 SKILL.md 第 2 步拿到完整视频文件（要画面，不能只要音频），记为 `V`。
2. **跑三个工具**，镜头图直接放进结果目录（Cowork 里也方便 device_stage_files）：
   ```
   $PY $VN_HOME/vtool.py shots  V "$OUT/<标题>/镜头"            # 切镜头：每镜头首/中/尾三帧拼图 + shots.json（亮度、饱和、黑边）
   $PY $VN_HOME/vtool.py beats  V "$OUT/<标题>/镜头/beats.json" --shots "$OUT/<标题>/镜头/shots.json"   # BPM、重音、断音，切点是否卡拍
   $PY $VN_HOME/vtool.py motion V "$OUT/<标题>/镜头/motion.json" --shots "$OUT/<标题>/镜头/shots.json"  # 运镜：推拉、上下、左右、速度曲线
   $PY $VN_HOME/vtool.py flow   V "$OUT/<标题>/镜头/flow"        # 逐帧连续分析：转场和运镜事件 + 时间线图 + 每个事件的逐帧图
   $PY $VN_HOME/vtool.py sheet  V $TMP/全片.jpg --n 24            # 全片联系表，先看一眼整体
   ```
   - **先看 `flow_timeline.png`，再看每个事件的逐帧图 `eNN_*.jpg`。** 静帧和联系表会漏掉连续的东西：形状匹配转场（发夹变成埃菲尔铁塔）、穿越推进、甩镜、旋转、遮挡转场、溶解。这些通常切不出镜头（shots 只报 1 个镜头），但在 flow 里会表现为"画面变化持续升高 + 运动速度激增 + 清晰度骤降"的一段。
   - flow 每帧都算（30fps 就是每秒 30 个点），不是抽样；事件的逐帧图每格约 0.1 秒，转场过程要逐格描述：从哪个物体/形状开始、镜头怎么动、在第几秒变成什么、怎么落定。
   - 判断不了是 AI 生成的形变还是实拍加剪辑时，如实写"推测"，并说明依据。
   - **运镜以 motion 的数字为准**，不要只凭几张静帧猜：静帧里人变小，可能是人走远，也可能是镜头后拉。看速度曲线在哪里变速，再和 beats 的重音、呼吸点对照。motion 的可信度低于 0.5 时（手持、主体大面积运动），结合逐帧图判断并注明。
   - 只切出 1 个镜头、但画面明显在变：一镜到底或柔性转场，以 flow 找到的事件为准。
   - 切点处、变装瞬间、动作细节，用 `sheet V $TMP/cutN.jpg --ss <切点-0.3> --to <切点+0.3> --n 9 --cols 3 --width 400` 放大看逐帧。
   - 有人声就照常 `transcribe`；Whisper 在纯音乐上会编出"字幕by xx"之类的假字，忽略即可。
3. **看图写分析**：先看全片联系表，再逐镜头看拼图。每个镜头按框架记录：景别、角度、运镜（比人物快还是慢）、构图、人物动作（方向、手接触什么）、穿搭、场景、光线、色调、画幅、声音、叙事功能、**为什么这样拍**。每个切点记录：转场方式、前后什么不变什么在变、离重音几毫秒。只写看得见的，不要编。
   - 帧很多（>40 张拼图）时分批交给子代理去看，各写一份文字，主对话只做汇总。
4. **氛围感与爆款分析**：按 `aesthetics-viral.md` 写氛围配方（光、色、空间、运动、声音）和传播机制（钩子、情绪、代入、可参与性、完播）。用户给的是链接、且有浏览器工具时，收集点赞、评论、收藏、转发、粉丝数、同款使用数和高赞评论作为证据；没有数据就注明是基于画面的推测。
5. **写复刻方案**：判断每段该实拍、图生视频还是文生视频；给出首帧图编辑提示词、按时间码写的视频提示词（中英各一版）、剪辑步骤（切点秒数、调色、黑边）。用户说复刻失败过，就按框架第五节逐条找原因。
6. **输出**到 `OUT/<标题>/`：
   - `画面拆解.md`：来源、规格和数据 → 一句话概括 → **为什么火**（爆款假设、氛围配方、传播机制、可迁移）→ 分镜表（每镜头一行，嵌入 `镜头/sNN_*.jpg`）→ 运镜与声画 → 切点与卡点 → 导演逻辑 → 可复用规则 → 复刻失败排查（用户提到时）
   - `复刻提示词.md`：每段的做法 → 首帧图编辑提示词 → 视频提示词（中/英）→ 剪辑步骤
   - `镜头/`：镜头拼图、shots.json、beats.json、motion.json（**这几张小图保留**，分镜表要用）
   - 清理：删视频和 `$TMP`，镜头拼图以外的截图都删。
