# 调研模式

用户说"调研/找一些 xx 视频""找 xx 教程""看看 xx 类视频为什么火"时使用。

## 1. 先确认目的，按目的定选样标准

开始前问清楚（或从请求里判断）是哪一类，再按对应标准挑视频：

| 目的 | 排序与筛选 | 理由 |
|---|---|---|
| **找教程** | 相关度优先；看收藏数和收藏/点赞比；限近 6～12 个月；看评论区有没有人说照做成功 | 收藏高通常是干货；工具类教程过期快 |
| **研究爆款** | 按"最多点赞"排序，限定时间范围（如近 3 个月）；算**点赞 ÷ 粉丝数**，优先小号也爆的；**另选几条同题材的普通视频做对照** | 大号天然点赞高，看不出内容本身的作用；没有对照组就找不到差异 |
| **竞品 / 账号调研** | 指定账号，取最近 N 条全部，不只挑最火的 | 要看真实的发布节奏和平均水平 |

- 平台自带筛选：抖音可按"最多点赞""最新发布"和发布时间筛选；B站可按播放、收藏、弹幕、发布时间排序（`bili search "关键词" --type video -n 10`）；小红书、抖音需要浏览器工具，在用户已登录的状态下搜；YouTube 用网页搜索找链接。
- 登录状态下的搜索结果是个性化的，在报告里说明。
- 排除广告、搬运、重复内容。每条记录：链接、作者、粉丝数、发布时间、点赞、评论、收藏、转发。

## 2. 先快筛，再深挖

- **快筛**（候选多时）：每条只读抖音页面自带的摘要、标题、互动数据，或请用户用豆包手机 App 批量获取大意，挑出值得细看的。
- **深挖**：入选的 3～5 条（爆款研究再加 2～3 条对照）逐条走完整流程；口播类转写加字幕校对，画面类走画面拆解模式。

## 3. 汇总

写 `调研_<主题>.md`，开头必须有**选样说明**：搜了什么关键词、用了什么排序和筛选、时间范围、为什么选这几条、排除了哪些、是否登录。正文按目的写：

- 教程：各条方法的异同、步骤汇总、哪条最完整、哪些已过期。
- 爆款：高赞与对照组在钩子、镜头时长、运镜、色调、转场、卡点、文案套路、互动数据上的差异，找出高赞的共同点；按 `aesthetics-viral.md` 给出爆款假设，注明单条结论只是假设。
- 竞品：发布节奏、平均数据、内容形式分布、可借鉴之处。
